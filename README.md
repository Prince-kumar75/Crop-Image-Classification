# Crop-Image-Classification
this project focuses on building a computer vision model that automates the identification of various crop types from images. By leveraging advanced machine learing techniques, the model aids in precision agriculture, enabling more efficient crop monitoring and disease detection in agriculture systems.

*Python, TensorFlow, Keras, CNN, NumPy, Streamlit*

- Developed a deep learning model to classify crop images into predefined categories using a Convolutional Neural Network (CNN).
- Implemented image preprocessing, normalization, feature extraction, and model training using TensorFlow and Keras.
- Evaluated model performance using validation accuracy and classification metrics.
- Built an interactive Streamlit web application for image uploads and crop predictions.
